# Veil OS v1.1.0

Veil OS 1.1.0 is based on Tails 7.17.1 and Debian trixie.

- The XFCE Wayland session registers its readiness with GDM. Early
  compositor failure can retry with software rendering. Loss of an
  established compositor uses the live system's shutdown path.
- Debian package installation and removal can register or unregister
  software through Tails Additional Software in encrypted persistence.
- Veil Package Center adds Debian search, installed and persistent views,
  repository and dependency details, and package actions.
- Wireshark's GUI moves to optional Debian APT. Bulk Extractor, ExifTool,
  AIDE, OpenSCAP and ClamAV are offered in optional Nix bundles.

See [the validation report](../test-results/1.1.0/README.md) for
tested behavior and outstanding release gates.
