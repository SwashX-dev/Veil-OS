## Verify before use

```
gpg --import veil-release-key.asc   # fingerprint DD86 CAC3 2D42 EADD 07F9  1054 670E 3A0F 5953 9633
gpg --verify SHA256SUMS.asc SHA256SUMS
sha256sum --check --ignore-missing SHA256SUMS
```
