# Veil OS 0.1.0-alpha.1

**Alpha. Unofficial Tails derivative. Not endorsed by the Tails project.**
Based on Tails 7.17.1 (signed tag `7.17.1`), built from Veil commit `f1c2c81`
with the official Tails build system.

> Use official Tails if your safety depends on it. This build is tested only
> in virtual machines.

## Downloads

| File | Use |
|---|---|
| `veil-amd64-0.1.0-alpha.1.img` | USB image (write to a stick of **8 GB or more**) |
| `veil-amd64-0.1.0-alpha.1.iso` | ISO (virtual machines, DVD) |
| `SHA256SUMS`, `SHA256SUMS.asc` | checksums + OpenPGP signature |
| `veil-amd64-0.1.0-alpha.1.packages`, `.build-manifest` | exact package list / build inputs |

## Verify before use

```
gpg --import veil-release-key.asc   # from docs/veil/ in the repository
gpg --fingerprint "Veil OS release"  # must be DD86 CAC3 2D42 EADD 07F9  1054 670E 3A0F 5953 9633
gpg --verify SHA256SUMS.asc SHA256SUMS
sha256sum --check --ignore-missing SHA256SUMS
```

## Highlights

- XFCE 4.20 on the **labwc Wayland** compositor (still no X.Org), with Veil branding
- Tor, firewall, amnesia, Persistent Storage, Tor Browser and Tor Connection behave
  as in Tails
- **Veil Agent**: local llama.cpp in a no-network sandbox. It is offline by
  default, and models download only on explicit request (SHA-256 verified)
- **Veil Network Guard**, **Veil Console**, **Package Center** (Nix bundles
  through Tor), offline labs
- Persistent Storage features: *Nix Packages*, *Veil Desktop Settings*

## Test results

20 of 24 requirements PASS, 3 PARTIAL, 1 UNTESTED, 0 FAIL. Boot time is on
par with official Tails 7.17.1 in the same harness (45.1 s vs 48.0 s to the
Welcome Screen). Full report: `docs/veil/TEST-REPORT.md`.

## Known limitations

- **No physical hardware tested.** GPU, Wi-Fi and Secure Boot are untested.
- No system tray on Wayland. Use the panel's Wi-Fi & Network button
  (GNOME Settings).
- Image reproducibility has not been verified yet.
- Some upstream strings still say "Tails".
