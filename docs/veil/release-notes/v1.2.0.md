# Veil OS v1.2.0

Veil OS 1.2.0 is based on Tails 7.17.1 and Debian trixie. **Prerelease:**
tested in QEMU/KVM only. Before relying on it, read
[the test report](../test-results/1.2.0/README.md).

## Fixes: random black screen, then power-off

- **Compositor restart:** 1.1.0 powered the computer off whenever the desktop
  compositor stopped. The compositor now restarts with software rendering,
  the screen lock comes back if the screen was locked, and a notification
  explains what happened. Six losses within five minutes still end in a
  normal shutdown, with the reason shown on screen.
- **Safe graphics on NVIDIA:** Tails drives NVIDIA GPUs with nouveau, and
  nouveau support for recent generations (for example RTX 40-series laptops)
  is young. On nouveau machines the desktop and applications now render in
  software by default. Add the `veil.gpu-rendering` boot option to opt out.
- **Safe Graphics boot entry:** uses no GPU driver at all (`nomodeset`).
- **USB stick removal:** Tails' emergency shutdown, which also looks like a
  black screen followed by power-off, now prints why it happened.
- `veil diagnostics --save` collects a redacted crash report.

## New: Privacy Center (Super+P, `veil privacy settings`)

- **Tor Browser security level** at startup (Tor Browser's own Standard,
  Safer or Safest; Veil never changes the browser's fingerprint).
- **Idle lock** after 10 minutes by default, only when a lock password exists.
- **Clipboard auto-clear.**
- **Emergency shutdown hotkey** (Ctrl+Alt+Shift+Delete).
- **Camera and microphone kill switches.**
- **VPN before Tor:** import a Proton VPN (or any WireGuard) configuration.
  Only Tor's connections use it, and it is fail-closed: if the VPN drops,
  Tor cannot connect directly. Connecting requires the administration
  password.
- **Video upscaling** in the new sandboxed Veil Player (Super+V):
  Quality, or Enhanced (FSRCNNX neural shader). `veil media upscale` makes
  1080p, 1440p or 4K copies of video files.
- **TCP timestamps** are disabled, so the computer's clock skew can't be used
  to recognize the same hardware across networks.

## Not included, and why

- **4- or 5-relay Tor circuits:** Tor has no supported option, and the Tor
  Project found longer paths add no meaningful anonymity. See
  [PRIVACY-CENTER](../PRIVACY-CENTER.md#tor-circuits-why-not-4-or-5-relays).
- **Tor → VPN** (VPN as the exit): WireGuard cannot run over Tor, and it
  would link your activity to an account.
- **Changes to Tor Browser's fingerprint:** these would make Veil users stand
  out.

Verify downloads with `SHA256SUMS` and `SHA256SUMS.asc` ([VERIFY](../VERIFY.md)).
