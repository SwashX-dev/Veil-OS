# Veil OS v1.1.1

Veil OS 1.1.1 is based on Tails 7.17.1 and Debian trixie. It fixes the screen going
black and the machine powering off by itself (a regression in 1.1.0).

- **Cause:** 1.1.0 shut the machine down whenever the desktop compositor (labwc) stopped
  after startup, so any compositor crash looked like a random blackout and power-off.
- **Fix:** the session now restarts the compositor with software rendering, restores the
  screen lock if the screen was locked, shows a notification, and records the exit
  status or signal in the journal. Open windows are lost, because applications exit with
  the compositor. Six losses within five minutes still end in a normal shutdown.
- **Not fixed:** why the compositor stops on some hardware is still unknown. If you see
  the notification, please report the reason it shows.
- If the machine still powers off with no notification and no restart, the cause is
  elsewhere. One candidate is Tails' emergency shutdown when the boot USB stick is
  removed or briefly disconnects (a flaky stick or port). That protection is unchanged.

**Status: prerelease.** Tested in QEMU/KVM only. Not tested on physical hardware.
Verify downloads with `SHA256SUMS` and `SHA256SUMS.asc` ([VERIFY](../VERIFY.md)).
Veil OS is unofficial and not endorsed by the Tails project.
