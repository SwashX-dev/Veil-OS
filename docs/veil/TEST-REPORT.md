### Comparison with official Tails 7.17.1 (same harness, same host)

| Metric | Tails 7.17.1 (official image) | Veil OS 0.1.0-alpha.1 |
|---|---|---|
| Power-on → Welcome Screen | 48.0 s | 45.1 s |
| Start → desktop ready | 16.9 s | 15.9 s |
| Tor routing / DNS & IPv6 leaks / kill switch / amnesia / internal-disk canary | PASS | PASS |
| ACPI power button | confirmation dialog (GNOME) | immediate clean power-off (6.3 s) |

Single runs, not averaged: treat differences below ~5 s as noise. Veil adds no measurable boot-time
cost; the image is ~120 MB larger (2.02 GB vs 1.90 GB).

### Defects found by testing and fixed before this release

| Found in | Defect | Fix |
|---|---|---|
| host tests | Agent sandbox resolved DNS through the nscd Unix socket (exfiltration channel) | mask all of `/run` when network is denied; `dns_resolution_blocked` self-test |
| build | `tcpdump` group took a GID Tails pins → Tails' ID-stability hook failed | `03-veil-pin-uids-gids` |
| build | llama.cpp Vulkan backend OOM-killed the compiler; upstream build fetched unpinned UI assets | `memory=8192`, RAM-based `-j`, UI download disabled |
| image 1 | Session deadlock: startup waited for Tor, Tor Connection waited for startup | `--no-block`, update check moved to `desktop.target` |
| image 1 | Tor Connection could not start: IBus not running outside GNOME | Veil session starts `ibus-daemon`; proxy waits for it |
| image 1 | Panel found no plugins: GDM's `XDG_DATA_DIRS` trailing slashes | `veil-session` normalizes it; internal-plugin panel |
| image 1 | Labs died with their launcher; nmap could not scan a same-namespace target | long-lived labs; target in its own network namespace |
| image 1 | Network Guard false positives on real Tails data (numeric UIDs, zram, relocated overlay, DHCP, TransPort) | fixed + real-data fixtures in unit tests |
| image 2 | Nix silently used a per-user chroot store → `nix profile` failed | pre-create `/nix/store`, `/nix/var/nix` |
| image 2 | checksec/rkhunter/chkrootkit absent (Tails purges binutils) | moved to Nix bundles / documented |

### Known limitations (not regressions against the requirements above)

- No physical hardware, Secure Boot, Wi-Fi chipset, GPU or NVIDIA testing.
- Vulkan GPU offload for the agent is built but untested (no GPU in the test VMs).
- Untested: input methods (IBus CJK), screen reader, and the screen magnifier under labwc.
- Some Tails strings still say "Tails" (initramfs messages, Tor Browser's start page, Persistent Storage texts).
- Cosmetic: the syslinux "SYSLINUX" title overlaps the splash. The Welcome Screen's "+" row is light.
- The upstream Tails Cucumber suite was not run. Its desktop scenarios target GNOME.
